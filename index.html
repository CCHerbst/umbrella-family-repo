New in beta 11

  • Filter availability above sources: CleanStream movies and VideoSkip movies/exact TV episodes, with cached background checks. Availability is not stream compatibility.
  • Inspect editions and notes: use the source context menu's Family filter availability / VideoSkip details option. No playback or filter download starts.
  • Manual landmark timing: pause on a reference in Parent Audit and confirm an offset for that exact stream/filter.
  • Optional OpenSubtitles downloads: find subtitles before playback using your own API key/account. Manual import remains the default.

Timing and coverage remain unverified. Background VideoSkip checks send the movie/show title, never stream URLs, and can be disabled in Family Filters settings. Subtitle downloads require explicit approval.

One-time setup in Kodi

  1. Enable Settings → System → Add-ons → Unknown sources, if needed.
  2. Open Settings → File manager → Add source. Name it Umbrella Family and enter:https://ccherbst.github.io/umbrella-family-repo/
  3. Choose Add-ons → Install from zip file → Umbrella Family, then select repository.umbrellafamily-1.0.0.zip.
  4. Choose Install from repository → Umbrella Family Repository (Beta) → Video add-ons → Umbrella Family → Install.
  5. Keep Auto-update enabled on the add-on information page and allow automatic updates in Kodi's global settings.

Updates arrive after a new release is published and Kodi checks the repository. For an immediate check, use Check for updates in Kodi's add-on browser.

Already using a beta?

This release installs separately as Umbrella Family. Export settings in the old beta's Tools menu, import them in the new add-on, restart Kodi, and disable the old beta.

Saved timing and filter files are not automatically moved. Recheck your settings before playback.
